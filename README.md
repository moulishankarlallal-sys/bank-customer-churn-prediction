# Predictive Modeling and Risk Scoring for Bank Customer Churn

## Project Overview
This project develops a machine learning system to predict bank customer churn and identify customers who may be at risk of leaving.

## Objectives
- Predict customer churn using classification algorithms.
- Generate customer-level churn probability scores.
- Identify key factors associated with customer churn.
- Compare Logistic Regression, Decision Tree and Random Forest models.
- Develop an interactive Streamlit application for churn risk assessment.

## Tools and Technologies
- Microsoft Excel
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Streamlit
- SHAP (for model explainability, if implemented)

## Project Workflow
1. Data cleaning and preprocessing
2. Exploratory data analysis
3. Feature engineering
4. Model training and evaluation
5. Churn probability scoring
6. Model explainability
7. Streamlit application development

## Expected Deliverables
- Excel-based customer analysis
- Exploratory data analysis notebook
- Trained churn prediction model
- Model evaluation report
- Interactive Streamlit application

## Business Value
The project aims to support proactive customer retention, targeted engagement and data-driven banking decisions.

*Model performance and findings will be reported after the models have been trained and evaluated.*
